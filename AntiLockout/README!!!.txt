If this is your first time installing AtmosphereOS, please run DeployAntiLockout.cmd as administrator to ensure you don't encounter any major issues. This swaps the Sticky Keys shortcut (sethc.exe) for the AntiLockout utility, keeping your original binary backed up so it can be restored later.

If you get locked out, press Shift 5 times on the login screen and select your account. AntiLockout will reactivate it so you can log back in. 
If that fails, activate the built-in Administrator account (by choosing the account called 'Administrator' in the AntiLockout utility) and talk to a developer in the Discord server or GitHub issues.

After installing, run the PostInstallRestore.cmd as administrator again to restore the original sethc.exe and to improve security.
